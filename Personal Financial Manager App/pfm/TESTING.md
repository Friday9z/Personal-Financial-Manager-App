# การทดสอบ

## A. Unit Test อัตโนมัติ (รันได้ทันที ไม่ต้องใช้เครื่อง)
`gradle :app:testDebugUnitTest` (GitHub Actions รันให้ทุกครั้งก่อน Build)

| ไฟล์ | ครอบคลุม |
|---|---|
| FinanceCalcTest | โอนเงินไม่เป็นรายรับ/รายจ่าย · บัตรเครดิต (ใช้จ่ายเพิ่มหนี้/ชำระไม่นับซ้ำ) · ชำระหนี้แยกต้น/ดอก/ค่าธรรมเนียม · ผ่อนหลายรายการในบัตรเดียว · แก้ไข/ลบรายการแล้วยอดปรับ · รายการประจำเดือน ก.พ./30/31 วัน/ปีอธิกสุรทิน/วันสิ้นสุด/ปิดใช้งาน · สัปดาห์เริ่มวันจันทร์ · งบประมาณและกันแจ้งเตือนซ้ำ · validate input |
| ReceiptParserTest | แยกยอด/วันที่ (รวม พ.ศ.)/เวลา/ร้าน/เลขอ้างอิงจากข้อความ OCR · Money parse/format |

สถานะ: เขียนและตรวจด้วยมือแล้ว **แต่ยังไม่เคยรันจริง** (ไม่มี SDK ในสภาพแวดล้อมที่เขียน)

## B. Checklist ทดสอบบนมือถือ (ต้องทำเอง)
Functional
- [ ] ตั้ง PIN ครั้งแรก / เปิดแอปใหม่ต้องใส่ PIN / กรอกผิด 5 ครั้งถูกล็อกชั่วคราว
- [ ] ลายนิ้วมือ / ใบหน้า (ต้องตั้งค่าในเครื่องก่อน) และ fallback เป็น PIN
- [ ] เพิ่มรายรับ / รายจ่าย (Quick Add และ Full Mode) → ยอด Home อัปเดตทันที + Snackbar
- [ ] แก้ไข / ลบรายการ จากหน้า Transaction Detail → ยอดบัญชีปรับ
- [ ] โอนเงินระหว่างบัญชี → รายรับ/รายจ่ายใน Report ไม่เปลี่ยน
- [ ] เพิ่มบัญชีธนาคาร / เงินสด / กระปุก / เป้าหมายเงินเก็บ (เพิ่ม-ถอน)
- [ ] ตั้งงบ → ใช้จ่ายให้ถึง 50/80/100% → ได้แจ้งเตือน ไม่ซ้ำ
- [ ] ตั้งรายการประจำ (อัตโนมัติ และแบบถามก่อน) → ไม่สร้างซ้ำเมื่อเปิดแอปหลายครั้ง
- [ ] เพิ่มบัตรเครดิต → จ่ายด้วยบัตร → วงเงินคงเหลือลด → ชำระบัตรจากบัญชี (ไม่ใช่รายจ่ายซ้ำ)
- [ ] เพิ่มรายการผ่อน 2 รายการในบัตรเดียว → จ่ายงวด → งวดคงเหลือลด
- [ ] ชำระหนี้ (แยกต้น/ดอก/ค่าธรรมเนียม) → หนี้คงเหลือลดเฉพาะเงินต้น
- [ ] สแกนใบเสร็จ → ตรวจ/แก้ไขข้อมูล → Save → เปิดดูรูปย้อนหลังได้
- [ ] Export Excel ทุกชนิด → เปิดด้วย Excel / Google Sheets, SUM คอลัมน์ Amount ได้
- [ ] Backup → ล้างข้อมูล/ติดตั้งใหม่ → Restore ข้อมูลกลับมาครบ
- [ ] สลับ Light / Dark / System ทุกหน้าเปลี่ยนตาม
- [ ] Weekly / Monthly Report ตรงกับรายการจริง

Data Integrity
- [ ] แก้ไขรายการย้อนหลัง · ลบรายการเก่า · ผ่อนหลายรายการ · เดือน ก.พ. / 30 / 31 วัน
- [ ] ปิดแอปแล้วเปิดใหม่ · รีสตาร์ทโทรศัพท์ · ปิดอินเทอร์เน็ตทั้งหมด (ต้องใช้งานได้ปกติ)
